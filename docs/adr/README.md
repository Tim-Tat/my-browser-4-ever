# Architecture Decision Records (ADRs)

Ein ADR hält eine technische Entscheidung fest: Kontext, Entscheidung, Begründung und Folgen. So bleibt nachvollziehbar, warum etwas so gebaut wurde.

**Regeln:**

- Eine Entscheidung pro Datei, fortlaufend nummeriert: `NNNN-kurzer-titel.md`.
- Angenommene ADRs werden nicht umgeschrieben. Ändert sich eine Entscheidung, kommt ein neuer ADR dazu, und der alte erhält den Status «Ersetzt durch ADR NNNN».
- Mögliche Status: Vorgeschlagen, Angenommen, Ersetzt.
